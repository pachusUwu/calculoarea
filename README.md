# Cálculo de Área – Actividad 3: Enfoque Modular y Diseño Top-Down (LPR 2026)

Programa modular en C++ que calcula el área de un círculo (A = π · r²) mediante la función `calcularAreaCirculo()`, valida el radio con un filtro de consistencia y dibuja una diana de tiro en ASCII según el tamaño.

**E.E.S.T. N.° 1 "Eduardo Ader" – Vicente López** · Laboratorio de Programación 5° 3° · Prof. Mansilla Muñoz York E.

## Compilar y ejecutar

```powershell
g++ src/main.cpp -o src/area.exe
.\src\area.exe
```

## Ejemplo

```
=> Ingrese el radio del circulo/diana (en cm): 10
[RESULTADO] El area del circulo es: 314.159 cm2
-> [DIANA ESTANDAR DE TIRO]
```
